Images folder

The website currently loads Wayanad photographs from the official DTPC Wayanad
website using image URLs referenced in:
- ../css/style.css
- ../js/script.js
- ../../index.html

The remote image host did not permit automated downloading during packaging,
so the original photo URLs are preserved. An internet connection is required
for these photos to appear. You can place locally licensed image files here
and update the corresponding image paths in the CSS and JavaScript files.
